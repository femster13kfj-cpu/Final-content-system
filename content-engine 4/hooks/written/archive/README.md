# Archive

Deep source libraries kept in full for variety mining. These are raw material, not working files: sessions pull from patterns.md and templates.md first, and dip into the archive only when the working palette feels repetitive and a fresh angle is needed.

- 1000-viral-hooks-library.pdf: the full 1,044-hook library (7 categories: Educational, Storytelling, Myth Busting, Authority, Comparison, Day in the Life, Random) with inspo links. The working template library in ../templates.md is distilled and adapted from this source; the source category map in ../patterns.md shows where each of the 7 categories lives in the five-goal system.

Mining rule: when pulling from the archive, adapt the hook into the repo's slot format and file it under the right goal section in templates.md. Never lift a line verbatim into a client post; adaptation is what keeps the output from being regurgitated.

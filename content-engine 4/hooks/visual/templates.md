# Visual Hook Templates: Repeatable Setups

Shot-ready setups per goal. Each is a checklist you can hand to anyone filming: frame, families used, text slot, and the verbal pattern it pairs with. Adapt to any niche; keep the Kyndle house style for branded assets.

## Goal 1: Capturing Leads
**Setup: Status Set + Command**
- Location matched to the claim's status (office/rooftop = authority advice; car/couch = hustle tips)
- Direct eye contact, framed chest-up, already mid-energy in frame one
- Text slot: the command, word for word with the spoken open
- Pairs with: Command Open, Money-Metric List
**Setup: Overlay Listicle**
- Static talking position; per-item price/earnings overlays timed to speech; product image per item
- Text slot: "[#] [things] that [money result]"
- Pairs with: Money-Metric List, Library Tease

## Goal 2: Authority
**Setup: Receipt Greenscreen**
- Greenscreen over the actual artifact (post, dashboard, article); zoom to the exact claim
- Receipt readable within 2 seconds of the spoken claim
- Pairs with: Proxy Open, Spoken News-Jack
**Setup: Artifact Desk**
- Desk framing with the physical prop (notes, printout, whiteboard) in hand; tap it when citing it
- Text slot: the percentile or promise
- Pairs with: Insider Percentile, Compression Promise
**Setup: Silent Thesis Card**
- Bold text card, 1-3 short parallel lines, over deliberately contrasting b-roll; 6-10 seconds total
- Pairs with: Parallel Fact Stack (no speech)

## Goal 3: Virality
**Setup: Mid-Attempt Open**
- The attempt already running in frame one; fragments land as overlays; no setup footage
- Pairs with: Fragment Stack, Rule-Setting Game
**Setup: Embodied Frame**
- Shoot when the environment IS the metaphor (weather, crowd, contrast); text overlay speaks what the frame shows
- Pairs with: Silent Hook (aphorism form), Micro Binary (show both options as b-roll)

## Goal 4: Connection
**Setup: Raw Walk**
- Phone selfie, walking outdoors, natural light, no mic in frame; plain text card naming the audience
- Pairs with: Identity Gate, Soft Promise
**Setup: Premise Card Over Now**
- The current chaotic/real moment fills frame one; simple past-premise text card on top; music, no speech
- Pairs with: Silent Hook (contrast form), Role Peek (text variant)
**Setup: POV Mission Entry**
- Camera walks into the location while the ask is spoken to someone in-scene
- Pairs with: Mission Ask, Role Peek Intro

## Goal 5: Educational
**Setup: Screen POV Tutorial**
- Open inside the screen/process; show the finished result in the first 2 seconds; zoom to tap targets
- Pairs with: Stat Reminder, Command Open (education form)
**Setup: Live Diagram Desk**
- Studio framing; the framework diagram/table draws itself in sync with each spoken step
- Mid-video comment-keyword card slot right before the final step
- Pairs with: Diagnosis, Percentage Formula, Named Challenge
**Setup: Finishing-Touch Macro**
- Extreme close-up; the micro-action starts in frame one; text label of the step; reveal at the end
- Pairs with: Silent Hook (process form)

## Cover slide setups [principle]
- **Number Cover:** big numeral + 5-word promise, one focal image, navy/green Kyndle system
- **Tension Cover:** text states the simple claim, image shows the chaotic or contrasting reality
- **Label Cover:** "[Superlative] [thing] [place/context]" over a single striking photo

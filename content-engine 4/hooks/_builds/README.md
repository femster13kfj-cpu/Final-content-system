# Builds

Finished content build documents: one file per piece of content, everything decided and fire-ready (hooks, slide copy, captions, generation prompts, grades). These are the system's worked examples; new sessions can study any file here to see every rule applied to a real topic.

Naming: YYYY-MM-[format]-[topic-slug].md
Status convention: each doc notes whether generation/publication has happened and with what results. When a build's post earns numbers, the numbers come back into this doc AND its winning hooks get promoted to the examples files; the performance module (/performance/GUIDE.md) owns that cadence and the verdict rules.

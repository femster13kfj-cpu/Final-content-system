# Verbal Structure: The Continuous Hook System

A hook is not a moment, it's a rhythm. The opening line buys roughly 3 seconds; after that the viewer's brain resets and looks for the next reason to stay. The algorithm rewards sustained watch time, not great openings. So the model is not hook then content then hope. It's hook, re-hook, re-hook, re-hook, close.

## The three layers

**Layer 1: Primary hook (0 to 3 seconds).** Its only job is to buy time. Established in under a second, visual and audio hitting together whenever possible. It opens the loop the rest of the video closes. This is the layer the verbal patterns and templates files feed.

**Layer 2: Secondary hooks (every 5 to 8 seconds, throughout).** Pattern interrupts that reset attention before boredom triggers the scroll reflex. The key rule: each re-hook must be a DIFFERENT type than the one before it. Mixing types creates the effect of multiple threads running inside one video.

**Layer 3: Close (final 5 seconds).** Resolve the loop the primary hook opened. Clean and definitive, no fluff. Optionally plant the seed for the next video, then apply the ramp check from conversion/funnel.md.

## The timed skeleton

```
0-3s    Primary hook: open loop, visual + audio double hit
3-8s    Secondary hook 1: first pattern interrupt
8-16s   Core value delivery: teach, show, prove
16-22s  Secondary hook 2: different type than 1
22-35s  Deeper value or proof: data, demo, story, prop
35-42s  Secondary hook 3: close the loop or open a new one
42-end  Close + ramp
```

Scale the timestamps proportionally for longer or shorter runtimes; the ratios matter more than the exact seconds.

## Secondary hook techniques

| Technique | Why it works | Where |
|---|---|---|
| Counterintuitive statement | "Wait, what?" forces re-engagement | 8-12s mark |
| Specific data drop | Numbers read as proof, trust resets | Middle |
| New prop introduced | New visual anchor resets the eye | Mid-video |
| Partial truth flip ("yes, but not the kind you think") | Disarms the skeptic, reopens curiosity | 10-20s |
| Curiosity re-open ("that's not even the best part") | New loop before the old one fully closes | Any lull |
| Identity or anti-authority line | Tribal re-engagement | Before mid-video CTA |
| Mid-video CTA | Leverages investment right before the payoff | Just before the answer |
| Zoom punch-in / b-roll cut / keyword overlay | Visual refresh under a steady voice | Every 8-10s of talking head |

## Pacing: the sweet spot

Something meaningful should land every 5 to 8 seconds. Too slow is boredom and a scroll. Too fast is sensory overload, which reads as confusion, which is also a scroll. The sweet spot is an effortless rhythm where the viewer never gets a quiet moment to consider leaving, so a 45-second video feels like 15.

## How this file interacts with the rest of the module

The goal sections in verbal/patterns.md supply the primary hook. This file supplies everything after second three. Every spoken line, primary or secondary, still passes the rubric's verbal checks: first three words graded as their own mini-hook, written for the ear, zero wind-up.
